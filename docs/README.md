# CapstoneDesk 2.0

CapstoneDesk is a modern, responsive web application for universities to manage student capstone projects. It supports three distinct roles:
1. **Admin**: Manage students, supervisors, and assign project groups.
2. **Supervisor**: Review assigned project groups, proposals, and milestones.
3. **Student**: Form groups, submit project proposals, and track progress.

## Tech Stack
- **Frontend**: React (Vite), React Router, Lucide React (Icons), Vanilla CSS (Custom Design System).
- **Backend**: Node.js, Express, Socket.io (Phase 2), Multer.
- **Database**: PostgreSQL (`pg` library).
